# Dissertação PPgTI

Repositório criado para armazenar os arquivos da dissertação do PPgTI

- **Requirements**:
    * SO host: Ubuntu 22.04.5 LTS (Jammy Jellyfish)
    * Virtualbox: VirtualBox 7.1.8 for Linux to Ubuntu 22.04
    * SO guest: Ubuntu 20.04.6 LTS (Focal Fossa)
    * You need to install Containernet, which includes Mininet-WiFi:
        - Containernet: https://github.com/ramonfontes/containernet
