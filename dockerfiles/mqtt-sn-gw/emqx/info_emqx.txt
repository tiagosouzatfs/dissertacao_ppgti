Instruções de inicialização do gateway mqtt-sn

https://hub.docker.com/layers/library/emqx/5.8.6/images/sha256-449f47353f15bc9d8e4b9d5da07b73fdff30b8b3e5f21963cd9a1a067d2a24f2

Inicie o xterm do serviço do gateway emqx e rode o comando:
    emqx foreground

curl -X 'PUT' 'http://127.0.0.1:18083/api/v5/gateways/mqttsn' \
  -u admin:public \
  -H 'Content-Type: application/json' \
  -d '{
  "name": "mqttsn",
  "enable": true,
  "gateway_id": 1,
  "mountpoint": "mqttsn/",
  "listeners": [
    {
      "type": "udp",
      "bind": "1884",
      "name": "default",
      "max_conn_rate": 1000,
      "max_connections": 1024000
    }
  ]
}'
